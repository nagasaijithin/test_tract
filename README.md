# Basic Details API

Node.js + Express REST API that returns basic details and can generate JSON from a DeepSeek prompt.

## Setup

```bash
npm install
cp .env.example .env
```

Set `DEEPSEEK_API_KEY` in `.env`. Get a key from [DeepSeek API](https://api-docs.deepseek.com/).

## Run

```bash
npm start
```

The server listens on `http://localhost:3000` (or `PORT` if set).

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| GET | `/` | Welcome message |
| GET | `/health` | Health check |
| GET | `/api/details` | Local app details and sample records |
| GET | `/api/details/:id` | One sample record by id |
| GET | `/api/deepseek/details` | Basic details generated by the configured DeepSeek prompt |
| POST | `/api/deepseek/chat` | Send `{ "prompt": "..." }` and return DeepSeek JSON |

### Chat example

```bash
curl -s http://localhost:3000/api/deepseek/chat \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Return JSON with name and summary for this API"}'
```
